## About

More than 25 years building for the web and more than 20 working with WordPress. I founded
Vudumedia, a design studio in Bilbao, and ran it for two decades. WordPress developer at Toptal and
WordPress expert at Codeable.

I’m currently Lead Engineer at [**Codedication**](https://codedication.com/), a studio focused on structured data, semantic SEO and modern WordPress block development.

## What I work on

- **Gutenberg block development** — TypeScript, the Interactivity API, block bindings, block themes
- **Structured data** — JSON-LD graphs, entity modelling, the engineering behind
[ValidGraph](https://validgraph.com/)
- **Front-end craft** — CSS-first interaction, animation and performance, no framework on the front
end unless it earns its place
- **Teaching** — a book, WordCamp talks and workshops across Spain

## The book

[**WordPress Editor and Blocks**](https://wp-block-editor.com/) is the complete guide to WordPress  
block development, updated for WordPress 7.0 and covering the Interactivity API and Block Bindings.  
It is the reference I wanted when I started building blocks and could not find.

Companion code repo: [wp-blocks-book](https://github.com/paulo-carvajal/wp-blocks-book)
